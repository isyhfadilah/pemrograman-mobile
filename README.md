# Pemrograman Mobile

Repository Pemrograman Mobile dibuat sebagai tempat penyimpanan seluruh project, tugas, dan latihan yang dikerjakan selama mengikuti mata kuliah Pemrograman Mobile. Repository ini mencerminkan proses pembelajaran dalam pengembangan aplikasi Android menggunakan bahasa pemrograman Java dan lingkungan pengembangan Android Studio.

Project yang terdapat dalam repository ini mencakup berbagai konsep dasar hingga menengah dalam pengembangan aplikasi mobile, seperti pembuatan Activity, penggunaan Intent, pengelolaan layout, penyimpanan data, serta interaksi pengguna.

---

## Getting Started

Panduan berikut akan membantu menjalankan dan mengeksplorasi project Android yang terdapat dalam repository ini.

---

### Prerequisites

Pastikan perangkat telah memenuhi kebutuhan berikut:

* **Android Studio** (versi terbaru direkomendasikan)
* **JDK (Java Development Kit)**
* Android SDK (biasanya otomatis terinstal melalui Android Studio)
* Emulator Android atau perangkat Android fisik
* Sistem operasi Windows / macOS / Linux

---

### Installing

Ikuti langkah berikut untuk menjalankan salah satu project:

1. Clone repository

   ```bash
   git clone https://github.com/isyhfadilah/pemrograman-mobile.git
   ```

2. Buka Android Studio

3. Pilih **Open an Existing Project**

4. Arahkan ke folder project yang ingin dijalankan

5. Tunggu proses Gradle Sync selesai

6. Jalankan aplikasi menggunakan:

   * Emulator Android
   * Perangkat fisik (USB Debugging aktif)

---

## Running the tests

Repository ini tidak menggunakan *automated testing framework*. Pengujian dilakukan secara manual melalui:

* Menjalankan aplikasi di emulator
* Menguji navigasi antar Activity
* Menguji validasi input pengguna
* Mengamati respons aplikasi terhadap interaksi pengguna

---

### Break down into end to end tests

Pengujian dilakukan berdasarkan skenario penggunaan aplikasi, seperti:

* Perpindahan antar halaman menggunakan Intent
* Penyimpanan dan pengambilan data
* Interaksi tombol dan komponen UI
* Respons aplikasi terhadap kondisi tertentu (error handling)

---

### And coding style tests

Penulisan kode mengikuti praktik dasar pengembangan Android:

* Struktur package yang terorganisir
* Pemisahan logic dan tampilan (Activity & Layout XML)
* Penamaan class dan method yang deskriptif
* Konsistensi indentasi dan format kode

---

## Deployment

Deployment dilakukan dengan:

* Build APK melalui Android Studio
* Generate Signed APK untuk distribusi

Namun, repository ini terutama ditujukan untuk keperluan akademik dan pembelajaran, bukan untuk distribusi publik melalui Google Play Store.
